# Telegram-бот проверки оплаты (Python, aiogram)

Участник выбирает тариф → переводит деньги → присылает чек боту → вы нажимаете «Подтвердить» →
бот выдаёт одноразовые ссылки в закрытые чаты. За 3 дня и за 1 день до конца срока бот предупреждает
участника (с кнопками продления), по окончании срока — удаляет из чатов (без вечного бана).

Цены берутся с сайта (`CONTENT_URL`), а если сайт недоступен — из `PRICE_MONTH` / `PRICE_QUARTER`.

## Установка на PythonAnywhere (платный тариф)

1. Загрузите папку `pybot` в `~/club-bot` (Files → Upload или `git clone`).
2. Откройте **Bash-консоль** и выполните:
   ```bash
   cd ~/club-bot
   python3.12 -m venv ~/.virtualenvs/club-bot        # подойдёт и 3.10–3.13
   ~/.virtualenvs/club-bot/bin/pip install -r requirements.txt
   cp .env.example .env && nano .env                 # заполните значения
   ```
3. Вкладка **Tasks → Always-on tasks → Create**, команда:
   ```
   /home/<ваш_логин>/.virtualenvs/club-bot/bin/python /home/<ваш_логин>/club-bot/main.py
   ```
   Запустите задачу. Лог смотрите по ссылке рядом с задачей: должно быть «Бот @… запущен».
4. После изменения `.env` или кода — **Restart** у задачи.

## Что нужно в `.env`

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_TG_IDS` | ваш Telegram id (через запятую, если админов несколько) |
| `RECEIPT_TG_IDS` | кому приходят чеки и кто подтверждает оплату (владелец группы; должен нажать Start у бота). Если пусто — все из `ADMIN_TG_IDS` |
| `GROUP_CHAT_IDS` | id закрытых чатов (`-100…`), бот — админ с правами «Приглашать» и «Блокировать» |
| `PAYMENT_DETAILS` | текст с реквизитами для перевода |
| `CONTENT_URL` | необязательно: `https://<ваш-сайт>/api/content` |

## Команды администратора

- `/members` — список участников и сроки.
- `/grant <id> <дней>` — выдать/продлить доступ вручную (оплата наличными и т. п.).

## Важно

- Отзовите старые пригласительные ссылки в чатах, иначе по ним войдут без оплаты.
- Участники хранятся в `data/members.json` рядом с ботом — делайте резервные копии.
- Запускайте только **одну** копию бота с этим токеном (иначе Telegram вернёт ошибку конфликта).
- Чек автоматически не проверяется: сумму и получателя сверяете вы. Повтор того же файла чека блокируется.
